# Hatsune Miku: Project S
A Godot project aimed to port the chart system from Hatsune Miku: Project Mirai DX to a PC game.

# Installation notes
The only playable song is Mesmerizer by 32ki, which chart is incomplete. Song file won't be provided to avoid copyright infringement, place it under /Game/Songs/mesmerizer.mp3. Other than that, the codebase is there if someone wants to polish the engine or release custom charts.
